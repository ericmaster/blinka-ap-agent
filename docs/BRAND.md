# Brand alignment with blinka.co

Source: `curl https://blinka.co/` + `/assets/main-CqMgimik.css` (fetched 2026-10-16). Logo NOT reused.

## Observed
- **CSS vars**: `--launch-ink:#1c253a`, `--launch-accent:#2a4bd0`, `--launch-paper:#f7f7f4`, `--launch-muted:#656975`, `--launch-line:#dedfdc`; dark mode ink `#e9edf1`, muted `#b2bbc7`, line `#b9c7da2b`.
- **Other frequent hexes**: `#b9c8ff` (soft blue), `#47525d`, `#111720`, `#fdfdfd`, `#d0d9e4`. (Reds/yellows/greens in HTML are country-flag SVGs, not brand.)
- **Fonts**: "Blinka Inter" (custom Inter) for UI; "Geist Mono Variable" for numbers/mono.
- **Radius**: pill buttons `999px`; cards 12/16/20px; small 2px/8px; avatars 50%.
- **Buttons** (`.launch-button`): ink bg, white text, pill, min-height 48px, padding 0 25px, 14px/500, hover `#334360` + shadow `0 3px 12px #1c253a14`; `.launch-primary` uses accent `#2a4bd0` (hover `#2342bd`); small variant 38px/12px.
- **Tone**: calm, confident, plain B2B finance. Hero: "The banking platform for global companies." Meta: "USD accounts, global payments, Visa Infinite cards, and treasury for global companies."

## Guidance
Off-white paper bg, navy ink text, single cobalt accent, pill CTAs, generous rounded cards, mono for amounts. Short declarative copy. Tokens: `docs/brand/tokens.css`.

## Name options (logos in docs/brand/, comparison `options.png`)
- **Clearhold** – "clear to pay, or hold": the core pay/hold decision. Mark: pause bars in rounded square.
- **Payclause** – pays only what the agreement's clauses allow. Mark: check in circle.
- **Agreedly** – pays what's agreed. Mark: two overlapping circles (invoice ↔ agreement match).
Quick web search (2026-10-16) found no obvious same-name software/fintech company for these three; not a trademark search.
